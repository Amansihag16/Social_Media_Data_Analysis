# SocialPulse – Power BI Dashboard Specification & Engineering Guide

## 1. Executive Summary & Architecture Overview

The **SocialPulse Intelligence Platform** surfaces multi-source social media analytics through an enterprise-grade 6-page interactive Power BI dashboard.
The data model connects directly to the **Gold Layer** analytical tables generated by our PySpark / Delta Lake pipeline.

### Connection Architecture
```
[Reddit / YouTube / Bluesky Feeds]
               │
               ▼
   [Bronze Delta Tables]
               │
               ▼
   [Silver Cleaned & Enriched Tables]
               │
               ▼
   [Gold Analytical Delta & CSV Tables]
               │
               ▼
   [Power BI Desktop / Service]
   (Direct Lake / Databricks SQL Warehouse / Gold CSV Import)
```

---

## 2. Dimensional Data Model (Star Schema)

The dashboard operates on a Star Schema optimized for performance and instant cross-filtering:

### Tables Overview:
1. **Fact Tables:**
   - `fact_gold_top_posts`: Detailed record level for high-engaging posts, metrics, sentiment scores, and direct URLs.
   - `fact_gold_daily_trends`: Daily time-series aggregates of post volumes, sentiment split, and engagement.
   - `fact_gold_hashtag_trends`: Granular hashtag counts, dates, platform, and engagement generated.
   - `fact_gold_customer_concerns`: Customer friction points, keywords, problem taxonomy, and negative sentiment.
   - `fact_gold_topic_analysis`: Keywords and sentiment breakdown.
2. **Dimension Tables:**
   - `dim_platform`: Unique platforms (`reddit`, `youtube`, `bluesky`), display logos, and channel categories.
   - `dim_date`: Calendar date, Year, Month, Week, Day of Week, Fiscal Quarter.
   - `dim_sentiment`: Sentiment labels (`Positive`, `Negative`, `Neutral`) and standard hex color codes.

### Relationships:
- `dim_date[Date]` (1) ───< (Many) `fact_gold_daily_trends[date]` (Single direction)
- `dim_platform[platform]` (1) ───< (Many) `fact_gold_top_posts[platform]` (Both directions)
- `dim_platform[platform]` (1) ───< (Many) `fact_gold_hashtag_trends[platform]` (Both directions)
- `dim_platform[platform]` (1) ───< (Many) `fact_gold_customer_concerns[platform]` (Both directions)

## 4. Production DAX Calculations & Measures

Create a dedicated measure table called `_Measures`:

### Core Volume & Engagement Measures
```dax
// 1. Total Posts
Total Posts = SUM(gold_daily_trends[total_posts])

// 2. Total Engagement
Total Engagement = SUM(gold_daily_trends[daily_engagement])

// 3. Average Engagement Per Post
Avg Engagement Per Post = 
DIVIDE(
    [Total Engagement],
    [Total Posts],
    0
)

// 4. Total Likes
Total Likes = SUM(gold_platform_performance[total_likes])

// 5. Total Comments
Total Comments = SUM(gold_platform_performance[total_comments])

// 6. Total Shares or Reposts
Total Shares = SUM(gold_platform_performance[total_shares])
```

### Sentiment Intelligence Measures
```dax
// 7. Positive Posts Count
Total Positive Posts = SUM(gold_daily_trends[positive_posts])

// 8. Negative Posts Count
Total Negative Posts = SUM(gold_daily_trends[negative_posts])

// 9. Neutral Posts Count
Total Neutral Posts = SUM(gold_daily_trends[neutral_posts])

// 10. Positive Sentiment %
Positive Sentiment % = 
DIVIDE(
    [Total Positive Posts],
    [Total Posts],
    0
)

// 11. Negative Sentiment %
Negative Sentiment % = 
DIVIDE(
    [Total Negative Posts],
    [Total Posts],
    0
)

// 12. Neutral Sentiment %
Neutral Sentiment % = 
DIVIDE(
    [Total Neutral Posts],
    [Total Posts],
    0
)

// 13. Net Sentiment Score (NSS)
// Measures overall brand sentiment index between -100 and +100
Net Sentiment Score = ([Positive Sentiment %] - [Negative Sentiment %]) * 100
```

### Hashtag & Customer Concern Measures
```dax
// 14. Total Hashtags Tracked
Total Hashtags = DISTINCTCOUNT(gold_hashtag_trends[hashtag])

// 15. Hashtag Total Engagement
Hashtag Engagement = SUM(gold_hashtag_trends[total_engagement])

// 16. Total Customer Complaints
Total Complaints Count = SUM(gold_customer_concerns[frequency])

// 17. High Risk Concern Index
High Risk Concern Index = 
CALCULATE(
    SUM(gold_customer_concerns[frequency]),
    gold_customer_concerns[sentiment_category] = "Negative"
)
```

## 5. Detailed Page-by-Page Visual Construction Guide

### PAGE 1: EXECUTIVE OVERVIEW
*Purpose: C-Suite and Director level dashboard summarizing overall brand health and cross-platform traction.*

1. **Top KPI Header Strip (Cards):**
   - Card 1: `Total Posts` (e.g. 20)
   - Card 2: `Total Engagement` (formatted as 28.5K / 1.2M)
   - Card 3: `Positive Sentiment %` (Green callout: `#10B981`)
   - Card 4: `Negative Sentiment %` (Red callout: `#EF4444`)
   - Card 5: `Net Sentiment Score` (Dynamic badge: +20 to +100 Green, -100 to -1 Red)
   - Card 6: `Active Connected Platforms` (Distinct count: 3)
2. **Visual 1 (Area Chart - Center Left):**
   - *Title:* Daily Post Volume & Total Engagement Over Time
   - *X-Axis:* `gold_daily_trends[date]`
   - *Y-Axis (Primary):* `Total Engagement`
   - *Y-Axis (Secondary):* `Total Posts`
3. **Visual 2 (Donut Chart - Center Right):**
   - *Title:* Overall Public Sentiment Breakdown
   - *Legend:* Sentiment (`Positive`, `Neutral`, `Negative`)
   - *Values:* Post Counts
   - *Colors:* Positive `#10B981`, Neutral `#6B7280`, Negative `#EF4444`
4. **Visual 3 (Clustered Bar Chart - Bottom):**
   - *Title:* Cross-Platform Post Volume and Interaction Share
   - *Y-Axis:* `platform`
   - *X-Axis:* `total_posts`, `avg_engagement_per_post`

---

### PAGE 2: SENTIMENT INTELLIGENCE
*Purpose: Deep-dive diagnostic into public sentiment trends, drivers, and polarity across platforms.*

1. **Visual 1 (100% Stacked Bar Chart):**
   - *Title:* Sentiment Distribution by Platform
   - *Y-Axis:* `gold_sentiment_summary[platform]` (Filter out `ALL_PLATFORMS`)
   - *X-Axis:* `positive_pct`, `neutral_pct`, `negative_pct`
2. **Visual 2 (Line Chart):**
   - *Title:* Net Sentiment Score (NSS) Daily Trajectory
   - *X-Axis:* `gold_daily_trends[date]`
   - *Y-Axis:* `[Net Sentiment Score]`
   - *Reference Line:* Constant line at `0` (Parity boundary)
3. **Visual 3 (Matrix / Table):**
   - *Title:* Top Positive Topics vs. Top Negative Discussion Vectors
   - *Rows:* `gold_topic_analysis[topic_keyword]`
   - *Columns:* `platform`
   - *Values:* `frequency`, `positive_count`, `negative_count`
4. **Visual 4 (Scatter Plot / Quadrant):**
   - *X-Axis:* `sentiment_compound`
   - *Y-Axis:* `engagement_score`
   - *Details:* `post_title`
   - *Tooltips:* Author, Platform, Sentiment Label

---

### PAGE 3: ENGAGEMENT ANALYTICS
*Purpose: Detailed engagement audit measuring reach, virality, comments, and post performance.*

1. **Top KPI Strip:**
   - Card 1: `Total Likes`
   - Card 2: `Total Comments`
   - Card 3: `Total Shares or Reposts`
   - Card 4: `Avg Engagement per Post`
2. **Visual 1 (Clustered Column Chart):**
   - *Title:* Platform-Wise Engagement Breakdown (Likes vs. Comments vs. Shares)
   - *X-Axis:* `platform`
   - *Y-Axis:* `total_likes`, `total_comments`, `total_shares`
3. **Visual 2 (Interactive Table):**
   - *Title:* Top 10 Most Engaging Posts Portfolio
   - *Columns:* `published_date`, `platform`, `post_title`, `sentiment_label`, `likes`, `comments`, `shares_reposts`, `engagement_score`, `post_url` (formatted as Web URL hyperlink icon)
   - *Conditional Formatting:* Background color on `sentiment_label` (Soft Green / Soft Red).

## 6. Global Slicers & Interactivity

Every page includes a standard top or left filter bar:
- **Date Range Slicer:** Between slider (`dim_date[Date]`).
- **Platform Dropdown Slicer:** Multi-select checkboxes (`reddit`, `youtube`, `bluesky`).
- **Sentiment Slicer:** Single-select tiles (`Positive`, `Negative`, `Neutral`, `All`).
- **Hashtag Search Slicer:** Searchable text dropdown.
